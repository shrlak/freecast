# FreeCast

KCCP 빛주사랑 대학청년부의 예배 프레젠테이션 앱입니다. 모든 슬라이드는 교회 PowerPoint와 같은 **4:3** 비율입니다. PowerPoint처럼 슬라이드를 편집하고, ProPresenter처럼 바로 발표하며, 주일예배 · 수련회 슬라이드를 교회 템플릿으로 만들어 줍니다.

## 다운로드

[**최신 버전 받기 → Releases**](https://github.com/shrlak/freecast/releases/latest)

| 컴퓨터 | 받을 파일 |
| --- | --- |
| Mac (Apple Silicon: M1 · M2 · M3 · M4) | `FreeCast-<버전>-arm64.dmg` |
| Mac (Intel) | `FreeCast-<버전>.dmg` |
| Windows 10 / 11 | `FreeCast-Setup-<버전>.exe` |

내 Mac이 어느 쪽인지 모르겠다면: 화면 왼쪽 위  메뉴 → **이 Mac에 관하여** → "칩"이 **Apple M…** 이면 Apple Silicon, "프로세서"가 **Intel** 이면 Intel입니다.

> `.zip`, `.blockmap`, `latest.yml`, `latest-mac.yml` 파일은 자동 업데이트용입니다. 직접 받을 필요가 없습니다.

## 설치 방법

### Mac

1. 내 Mac에 맞는 `.dmg` 파일을 받아서 엽니다.
2. 열린 창에서 **FreeCast** 아이콘을 **Applications(응용 프로그램)** 폴더로 끌어다 놓습니다.
3. 처음 한 번만: **응용 프로그램** 폴더에서 FreeCast를 **오른쪽 클릭(또는 Control-클릭) → 열기 → 열기**를 누릅니다.
   - 앱이 아직 Apple 인증서로 서명되지 않아서 그냥 더블클릭하면 "확인되지 않은 개발자" 경고가 뜹니다.
   - 그래도 열리지 않으면: **시스템 설정 → 개인정보 보호 및 보안** 아래쪽의 "FreeCast"에서 **그래도 열기**를 누릅니다.
4. 그다음부터는 평소처럼 더블클릭으로 열면 됩니다.

### Windows

1. `FreeCast-Setup-<버전>.exe` 를 받아서 실행합니다.
2. "Windows의 PC 보호" 파란 창이 뜨면 **추가 정보 → 실행**을 누릅니다. (앱이 아직 코드 서명되지 않았기 때문입니다.)
3. 설치 마법사를 따라 설치합니다. 바탕화면과 시작 메뉴에 FreeCast가 생깁니다.

## 자동 업데이트

설치한 뒤에는 따로 다시 받을 필요가 없습니다. FreeCast는 **운영체제를 따라 업데이트**됩니다.

- **macOS(또는 Windows)가 업데이트된 뒤 FreeCast를 처음 켤 때** 새 버전이 있는지 확인합니다. 평소에는 저절로 확인하지 않습니다.
- 새 버전이 있으면 알림을 띄우고 뒤에서 내려받은 다음, **앱을 종료할 때 자동으로 설치**합니다. 다음에 켜면 새 버전입니다.
- 예배 중에는 절대 저절로 재시작하지 않습니다. 바로 설치하려면 알림이나 위쪽 배너의 **지금 재시작하여 업데이트**를 누르세요.
- 언제든 직접 확인하려면: Mac은 메뉴 **FreeCast → Check for Updates…**, 또는 **화면 설정 → 소프트웨어 업데이트 → 업데이트 확인**.

## 처음 쓸 때

- **로그인 (선택)**: 오른쪽 위 **☁ 로그인 → 계정 만들기**에서 아이디·비밀번호와 **관리자 비밀번호**(주일예배 생성기의 관리자 설정과 같은 비밀번호)를 넣으면 계정이 생깁니다. 로그인하면 슬라이드가 교회 서버에 저장되어 다른 컴퓨터에서도 열립니다.
- **이번 주 예배**: **예배** 탭 → **예배 열기**. 콘티 PDF, 가사 파일, 설교 PPTX를 버튼으로 올리거나 창에 끌어다 놓으면 그 자리에 바로 들어갑니다.
- **기도제목 · 날짜**: **예배** 탭 → **🙏 기도제목**에 이번 주 기도제목을 적으면 주일예배 Front의 기도 준비 슬라이드에 들어갑니다. Front 두 번째 슬라이드의 날짜는 매주 그 주 주일 날짜로 저절로 바뀝니다.
- **공동체 고백송**: 학기마다 · 해마다 바뀌는 고백송은 **예배** 탭 → **🙌 공동체 고백송**에서 찬양 라이브러리의 노래를 골라 저장하면 됩니다. 주일예배 Back 슬라이드의 고백송 부분이 그 노래로 바뀝니다. (한 주만 다른 노래를 쓰려면 주일예배 마법사에서 바꾸세요.)
- **발표**: **▶ 발표** 또는 F5 (처음부터), Shift+F5 (현재 슬라이드부터), Esc (끝내기). PowerPoint처럼 연결된 프로젝터·TV에 바로 전체 화면으로 뜨고 (화면 설정에서 고른 화면이 있으면 그 화면), 화면이 하나뿐이면 이 화면을 덮습니다. 발표를 끝내면 그 창도 닫힙니다.
- **어디서나 리모컨**: **⚙ 화면 설정 → 인터넷 리모컨**을 켜면 휴대폰에서 FreeCast를 조작할 수 있습니다. PIN은 없고, 링크(또는 QR)를 아는 사람만 접속합니다. 링크는 교회 Worker에 한 번만 설정(`worker/remote-link.js` 안내 참고)하면 **FreeCast를 다시 켜도 같은 주소**로 유지되고, **New Link** 버튼을 눌러야만 바뀝니다 (이전 링크는 즉시 막힙니다). Worker 설정 전에는 켤 때마다 바뀌는 임시 주소가 표시됩니다.
- **OBS 방송**: **슬라이드 쇼** 탭의 **⚙ 화면 설정**에서 OBS용 출력(브라우저 소스)을 켭니다.

## 키보드 단축키

Mac은 **⌘**, Windows는 **Ctrl**을 누르세요. (글자를 입력하는 중에는 단축키가 동작하지 않습니다.)

### 발표

| 키 | 동작 |
| --- | --- |
| F5 | 처음부터 발표 |
| Shift+F5 | 현재 슬라이드부터 발표 |
| Esc | 발표 끝내기 |
| → ↓ PageDown Space | 다음 슬라이드 |
| ← ↑ PageUp | 이전 슬라이드 |
| B | 검은 화면 켜기/끄기 |
| L | 로고 켜기/끄기 |
| F1 | 화면 모두 지우기 |
| F2 | 글자만 지우기 |
| F3 | 배경만 지우기 |
| F4 | 소품(Props) 모두 지우기 |
| F6 | 광고 반복 화면 멈추기 |
| 슬라이드에 지정한 한 글자 | 그 슬라이드로 바로 이동 (슬라이드 설정의 "Hotkey"; 해당 프레젠테이션이 선택되어 있을 때) |

- 클래식 레이아웃에서는 F5가 화면의 메시지를 지웁니다 (발표 시작은 ▶ 버튼).
- 청중 화면 창에서 **F** 또는 더블클릭은 전체 화면 전환이고, 그 외의 키는 모두 위의 발표 키로 전달됩니다.

### 편집

| 키 | 동작 |
| --- | --- |
| ↑ ↓ ← → PageUp PageDown | 왼쪽 슬라이드 목록에서 이동 (다음 프레젠테이션으로 이어짐) |
| Enter | 현재 슬라이드 뒤에 **흰 배경의 빈 슬라이드** 추가 |
| Backspace / Delete | 선택한 슬라이드 삭제 |
| Shift+클릭 / ⌘·Ctrl+클릭 | 슬라이드 여러 장 선택 |
| ⌘/Ctrl+D | 슬라이드 복제 |
| ⌘/Ctrl+V | 복사한 그림·스크린샷을 새 슬라이드로 붙여넣기 |
| ⌘/Ctrl+Z | 실행 취소 |
| ⌘/Ctrl+Shift+Z | 다시 실행 |
| ⌘/Ctrl+F | 라이브러리 검색창으로 이동 |
| ⌘/Ctrl+K | **빠른 찾기** — 모든 프레젠테이션에서 가사·성경 구절·광고를 찾기. ↑↓ 이동, Enter 화면에 바로 표시, Shift+Enter 편집, Esc 닫기 |

🔒 **잠금**(화면 아래 상태 표시줄, 기본 켜짐): 슬라이드가 화면에 표시되는 동안에는 Enter·Backspace·Delete로 슬라이드를 추가하거나 삭제할 수 없고, 화면에 나가고 있는 슬라이드의 개체도 지워지지 않습니다. 실수 방지용이며, 누르면 해제됩니다.

### 슬라이드 위의 개체 (선택했을 때)

| 키 | 동작 |
| --- | --- |
| ↑ ↓ ← → | 1칸씩 이동 (Shift를 누르면 10칸) |
| Alt+끌기 | 정렬선에 붙지 않고 자유롭게 이동 |
| Enter | 글자 입력 시작 |
| Delete / Backspace | 개체 삭제 |
| Esc | 선택 해제 (글자 입력 중에는 입력 끝내기) |

### 글자 서식

| 키 | 동작 |
| --- | --- |
| ⌘/Ctrl+B · I · U | 굵게 · 기울임 · 밑줄 |
| ⌘/Ctrl+L · E · R · J | 왼쪽 · 가운데 · 오른쪽 · 양쪽 맞춤 |
| ⌘/Ctrl+] · [ | 글자 크게 · 작게 |

### 창 (데스크톱 앱 메뉴)

| 키 | 동작 |
| --- | --- |
| ⌘/Ctrl+1 | 청중 화면 열기 |
| ⌘/Ctrl+2 | 무대 화면 열기 |
| ⌘/Ctrl+Shift+W | 열린 출력 창 모두 닫기 |
| ⌘/Ctrl+Shift+R | 새로고침 |

## 개발

```bash
npm install
npm run dev        # 브라우저에서 개발 (http://localhost:5173)
npm test           # 테스트
npm run app        # 데스크톱 앱으로 실행
npm run dist       # 설치 파일 만들기 (release/ 폴더)
```

새 버전을 내려면 `package.json`의 버전을 올리고 설치 파일을 만든 뒤, 같은 버전 태그(`v0.1.2` 등)로 GitHub Release에 모든 설치 파일과 `latest.yml` · `latest-mac.yml`을 올립니다. 설치된 앱은 이 Release를 보고 스스로 업데이트합니다.
