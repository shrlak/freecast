FreeCast
사용 설명서

처음 쓰는 사람도 10분이면 예배 화면을 띄울 수 있어요

이 설명서는 꼭 필요한 것만 담았어요.
① 설치 → ② 화면 보기 → ③ 이번 주 예배 만들기 → ④ 발표하기
이 네 가지만 알면 주일예배를 진행할 수 있어요.

FreeCast는 PowerPoint처럼 슬라이드를 만들고, 예배 중에는 버튼 하나로 프로젝터에 띄우는 예배용 프레젠테이션 앱이에요. 모든 슬라이드는 교회 PowerPoint와 같은 4:3 비율이에요.

차례

처음이라면 1번부터 4번까지 순서대로 읽어 보세요.

💡 이것만 기억하세요 실수해도 괜찮아요. ⌘/Ctrl + Z 를 누르면 방금 한 일이 취소되고, 지운 자료는 휴지통에 30일 동안 남아 있어요.
✅ 업데이트는 신경 쓰지 않아도 돼요 한 번 설치하면 FreeCast가 스스로 새 버전을 받아서, 앱을 끌 때 설치해요. 예배 중에 갑자기 재시작하는 일은 없어요.

1설치하기

처음 한 번만 하면 돼요. 그다음부터는 자동으로 업데이트돼요.

내려받기

인터넷 주소창에 아래 주소를 열고, 내 컴퓨터에 맞는 파일 하나만 받으세요.

github.com/shrlak/freecast/releases/latest

내 컴퓨터받을 파일
Mac (M1 · M2 · M3 · M4)FreeCast-버전-arm64.dmg
Mac (Intel)FreeCast-버전.dmg
Windows 10 / 11FreeCast-Setup-버전.exe
내 Mac이 어떤 건지 모르겠다면 화면 왼쪽 위 → 이 Mac에 관하여. “칩: Apple M…”이면 위쪽 파일, “프로세서: Intel”이면 아래쪽 파일이에요.

🍎 Mac

  1. 받은 .dmg 파일을 더블클릭해요.
  2. FreeCast 아이콘을 Applications(응용 프로그램) 폴더로 끌어다 놓아요.
  3. 처음 한 번만: 응용 프로그램 폴더에서 FreeCast를 오른쪽 클릭 → 열기 → 열기.
  4. 그래도 안 열리면: 시스템 설정 → 개인정보 보호 및 보안 맨 아래 그래도 열기를 누르고 Mac 암호를 넣어요.

🪟 Windows

  1. 받은 .exe 파일을 더블클릭해요.
  2. 파란 “Windows의 PC 보호” 창이 뜨면 추가 정보 → 실행.
  3. 안내대로 다음을 눌러 설치해요.
  4. 바탕화면의 FreeCast 아이콘으로 열어요.
⚠ 경고 창이 떠도 놀라지 마세요 “확인되지 않은 개발자”, “PC 보호” 같은 창은 앱이 아직 유료 인증서로 서명되지 않아서 뜨는 거예요. 바이러스가 아니에요. 위 방법대로 한 번만 열어 주면 다음부터는 바로 열려요.

로그인 (권장)

오른쪽 위 ☁ 로그인을 눌러 로그인하면 슬라이드가 교회 서버에 저장돼서 다른 컴퓨터에서도 똑같이 열려요. 계정이 없으면 계정 만들기에서 아이디 · 비밀번호와 관리자 비밀번호(미디어팀장에게 물어보세요)를 넣으면 돼요. 로그인하지 않으면 이 컴퓨터에만 저장돼요.

2화면 한눈에 보기

PowerPoint와 거의 같아요. 빨간 숫자만 기억하세요.

1위쪽 탭 — 파일 · 홈 · 삽입 · 디자인 · 슬라이드 쇼 · 예배 · 도구. 예배 준비는 거의 다 예배 탭에 있어요.
2▶ 발표 — 노란 버튼. 누르면 프로젝터에 바로 띄워요.
3⚙ 설정 — 어느 모니터(프로젝터)에 띄울지, 휴대폰 리모컨 등을 정해요.
4왼쪽 창 — 슬라이드(지금 예배 순서) · 라이브러리(저장된 찬양 · 자료) · 미디어(배경 · 그림 · 영상).
5가운데 — 지금 고른 슬라이드. 글자를 눌러 바로 고칠 수 있어요.
6오른쪽 서식 — 글자 내용 · 글꼴 · 크기 · 배경을 바꿔요.
7노트 — 여기에 적은 메모는 청중에게는 안 보이고, 무대(찬양팀 · 설교자) 화면에만 보여요.
8🔒 잠금 · 보기 — 잠금이 켜져 있으면 화면에 나가는 슬라이드를 실수로 지울 수 없어요. 옆 버튼으로 보기 방식을 바꿔요.

3이번 주 예배 만들기

교회 템플릿(Front · 찬양 · 말씀 · 설교 · 광고 · Back)으로 자동으로 만들어 줘요.

가장 쉬운 방법: 주일예배 마법사

  1. 위쪽 예배 탭 → 📝 주일예배 마법사를 눌러요.
  2. 1. 찬양: Upload 콘티 PDF로 콘티를 올리면 곡 제목 · 키 · 순서 · 가사를 읽어 와요. 카톡 공지를 붙여 넣어도 돼요.
  3. 2. 성경 말씀: 본문(예: 로마서 12:1-2)을 넣어요.
  4. 3. 설교: 설교 제목을 넣고, 설교 PPT가 있으면 올려요.
  5. 4. 기도회 · 기도제목: 기도회 찬양 제목을 넣고 🔎 PPT 찾기를 누르면 악보를 인터넷에서 찾아와요.
  6. 5. 광고 · 6. 추가 자료를 채우고, 7. 생성을 누르면 완성!

오른쪽 아래 다음으로 넘어가요. 쓰다가 닫아도 자동 저장돼요.

💡 한 부분만 고치고 싶을 때 마법사를 처음부터 다시 할 필요 없어요. 예배 탭의 단계별 수정에서 찬양 수정 말씀 수정 설교 수정 광고 수정 중 필요한 것만 누르세요.
💡 파일만 바로 넣고 싶을 때 ⛪ 예배 열기 후 콘티 업로드 가사 올리기 설교 슬라이드를 누르거나, 파일을 창에 끌어다 놓으세요.

4프로젝터에 띄우기 (발표)

예배 당일, 이 페이지만 보면 돼요.

처음 한 번: 어느 화면에 띄울지 정하기

  1. 컴퓨터에 프로젝터(또는 TV)를 연결해요.
  2. 오른쪽 위 ⚙ → 출력 화면을 눌러요.
  3. “어느 모니터에 띄울까요?”에서 프로젝터를 골라요. 다음부터는 기억해요.

예배 중

  1. 노란 ▶ 발표 버튼(또는 F5)을 누르면 프로젝터에 전체 화면으로 떠요.
  2. → 또는 Space로 다음, ←로 이전 슬라이드.
  3. 왼쪽 목록에서 아무 슬라이드나 클릭하면 그 슬라이드로 바로 가요.
  4. 끝나면 Esc.
이럴 땐누르세요
화면을 잠깐 까맣게 (기도 시간 등)B  다시 누르면 돌아와요
교회 로고만 보여 주기L
글자만 지우고 배경은 두기F2
화면 모두 지우기F1
지금 슬라이드부터 발표 시작Shift + F5
⚠ 프로젝터에 아무것도 안 나와요 ① 케이블이 꽂혀 있는지 ② ⚙ → 출력 화면에서 프로젝터가 골라져 있는지 확인하세요. 출력 창이 엉뚱한 화면에 떴다면 그 창을 프로젝터 쪽으로 끌어다 놓고 F를 누르면 전체 화면이 돼요.
✅ 무대 화면 찬양팀 · 설교자용 모니터에는 슬라이드 쇼 탭 → 🎤 무대 화면을 열어 두세요. 지금 · 다음 슬라이드, 노트, 시계가 보여요.

5휴대폰으로 슬라이드 넘기기

컴퓨터에서 멀리 있어도 휴대폰 · 태블릿으로 넘길 수 있어요. 앱 설치는 필요 없어요.

  1. 컴퓨터에서 ⚙ → 리모컨 · 휴대폰을 눌러요.
  2. 어디서나 리모컨을 켜요.
  3. 화면에 나온 QR 코드를 휴대폰 카메라로 찍어요.
  4. 휴대폰에 리모컨이 열려요. ◀ 이전 / 다음 ▶을 누르면 돼요.
💡 알아 두면 좋아요
  • 처음 연결한 휴대폰이 바로 조작할 수 있고, 다른 기기는 보기 전용으로 들어와요. 필요하면 조작권 요청을 눌러요.
  • 위쪽 휴대폰 0 숫자는 지금 연결된 휴대폰 수예요.
  • 목사님 태블릿은 리모컨 위쪽 🎤 무대 화면을 누르면 말씀 · 다음 슬라이드 · 시계가 크게 보여요.
🔐 QR 코드는 미디어팀에만 QR 코드(링크)를 아는 사람은 누구나 슬라이드를 넘길 수 있어요. 단체방에 올리지 마세요.

6자주 쓰는 작업

대부분 이 다섯 가지면 충분해요.

✏️ 글자 고치기

가운데 슬라이드의 글자를 클릭해서 바로 고치거나, 오른쪽 서식 창의 본문 · 가사 칸에서 고쳐요. 저장 버튼은 없어요 — 자동 저장돼요.

🎵 찬양 · 자료를 예배 순서에 넣기

  • 검색해서: 왼쪽 슬라이드 탭 맨 아래 ＋ 이 재생목록에 곡·자료 넣기에 제목이나 가사를 치고 결과를 눌러요.
  • 끌어서: 라이브러리에서 곡을 원하는 자리로 끌어다 놓아요. 순서도 끌어서 바꿔요.

⚡ 빠르게 찾아서 띄우기

⌘/Ctrl + K 를 누르고 가사 · 성경 구절 · 광고 한 단어를 치면 모든 자료에서 찾아요. Enter를 누르면 화면에 바로 떠요.

➕ 슬라이드 추가 · 삭제

왼쪽 목록에서 슬라이드를 고르고 Enter = 뒤에 빈 슬라이드 추가, Delete = 삭제, ⌘/Ctrl+D = 복제.
(삭제가 안 되면 아래쪽 🔒 잠금이 켜져 있는 거예요. 발표 중 실수를 막는 기능이에요.)

↶ 되돌리기

  • 방금 한 일: ⌘/Ctrl + Z
  • 지운 자료: 파일 탭 → 🗑 휴지통 (30일 동안 복원 가능)
  • 예전 상태로 통째로: 파일 탭 → 🕘 복원 지점

8문제가 생겼을 때

당황하지 말고 아래부터 확인해 보세요.

Mac에서 “손상되었기 때문에 열 수 없습니다”가 떠요.

옛날 버전(0.7.6 이하)을 받은 경우예요. 최신 버전을 다시 받으면 1장 방법으로 열려요. 지금 바로 열어야 하면 응용 프로그램 → 유틸리티 → 터미널에 아래 한 줄을 붙여 넣고 Return을 누르세요.

xattr -cr /Applications/FreeCast.app
프로젝터에 화면이 안 나와요.

케이블 확인 → ⚙ → 출력 화면에서 프로젝터 선택 → Esc 후 다시 F5. 창이 다른 모니터에 떴다면 프로젝터 쪽으로 끌어다 놓고 F.

슬라이드가 안 지워져요 / Enter를 눌러도 슬라이드가 안 생겨요.

화면 아래 🔒 잠금이 켜져 있어서예요. 발표 중 실수 방지 기능이에요. 누르면 풀려요. 자료에 자물쇠(자료 보호)가 걸려 있어도 고칠 수 없어요 — 홈 → 자료 보호 해제.

실수로 지웠어요!

⌘/Ctrl+Z → 안 되면 파일 → 휴지통 → 그래도 없으면 파일 → 복원 지점.

인터넷이 끊겼어요.

괜찮아요. 슬라이드는 항상 이 컴퓨터에 먼저 저장되기 때문에 발표는 그대로 돼요. 인터넷이 돌아오면 자동으로 동기화해요.

다른 컴퓨터에서 고친 내용이 안 보여요.

두 컴퓨터 모두 같은 계정으로 로그인되어 있는지 확인하세요. 오른쪽 위 ☁ 계정 이름을 누르면 동기화 상태가 보여요.

휴대폰 리모컨이 안 눌려요.

보기 전용으로 연결된 거예요. 리모컨의 조작권 요청을 누르거나, 컴퓨터에서 직접 넘기세요. 연결이 끊기면 자동으로 다시 연결돼요.

새 버전이 있다는데 어떻게 해요?

아무것도 안 해도 돼요. 앱을 끌 때 자동으로 설치돼요. 바로 하려면 위쪽 배너의 지금 재시작하여 업데이트. (예배 중에는 누르지 마세요!)

여기 없는 문제는 미디어팀장에게 물어보세요. 모든 기능의 자세한 설명은 GitHub의 README에 있어요.
